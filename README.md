# ✦ Heartopia Bot

โปรแกรมบอทช่วยเล่นเกม Heartopia พัฒนาด้วยภาษา Python (Tkinter + PyAutoGUI) รองรับการสแกนจับภาพวัตถุบนหน้าจอและการทำงานอัตนัติแยกเป็นหมวดหมู่

---

## 📂 โครงสร้างโปรเจกต์ (Project Structure)
```text
BOT_CONTROLLER/
├── images/             # โฟลเดอร์เก็บทรัพยากรรูปภาพแยกหมวดหมู่
│   ├── berry/          # รูปภาพและ Preset สำหรับโหมด Berry
│   ├── cooking/        # รูปภาพสำหรับเมนูและขั้นตอนการทำอาหาร
│   └── snow/           # รูปภาพปุ่มและไอคอนในกิจกรรมหิมะ
├── bot_controller.py   # หน้าต่างควบคุมหลัก (Main GUI Terminal)
├── bot_berry.py        # ระบบบอทเก็บเบอร์รี่อัตโนมัติ
├── bot_berry3tree.py   # ระบบบอทเดินเก็บเบอร์รี่แบบ 3 ต้นพร้อมกัน
├── bot_cooking.py      # ระบบบอททำอาหาร (โหมดเซฟ / โหมดสับไฟหลายครั้ง)
├── bot_snow.py         # ระบบบอทฟาร์มหิมะอัตโนมัติ
└── bot_chop.py         # ระบบบอทตัดไม้/ทุบหินกดตามจังหวะ
```
🚀 ฟังก์ชันการใช้งานหลัก (Core Features)
🍒 โหมด Berry: ช่วยกดคลิก Interact และคำนวณระยะเวลาเดิน (Walk/Back Cooldown) ระหว่างต้นเบอร์รี่ เลือกสลับโหมดได้ทั้งแบบ 1 ต้น, 2 ต้น หรือ 3 ต้น

🍳 โหมด Cooking: ตรวจจับปุ่มเริ่มทำอาหารและปุ่มจังหวะสับไฟ มีระบบเปลี่ยนคิวเมนูอาหารอัตโนมัติเมื่อวัตถุดิบเดิมหมด

❄️ โหมด Snow: ค้นหาจุดหิมะบนหน้าจอและปาหิมะอย่างรวดเร็ว พร้อมระบบนับยอดสถิติจุดที่กดสำเร็จ

🛠️ วิธีการติดตั้งและการใช้งาน (Setup Guide)
ติดตั้ง Library ที่จำเป็น:

```Bash
pip install pyautogui pydirectinput keyboard pygetwindow
```
รันโปรแกรม:
```
Bash
python bot_controller.py
```

การสั่งการ: เปิดหน้าต่างเกมขึ้นมา จากนั้นกดปุ่ม 🔄 ล็อคเป้าใหม่ บนหน้าต่างบอทเพื่อทำการ Sync พิกัดขอบจอเกม จากนั้นกดคีย์ลัด F9 (Berry), F10 (Cooking), หรือ F11 (Snow) เพื่อเริ่มทำงานได้ทันที

ปล.ยังไม่ค่อยสมบูรณ์ใครอยากเอาไปใช้ ใช้ในห้องมืดไม่มีคนกับผมสีดำ
